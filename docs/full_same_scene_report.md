# 全量实验一至三：同场景诊断结果

**结果标签：`same_scene_diagnostic`／同场景诊断。不是独立图像泛化测试，不是真实在线相机闭环，不作为论文方法优越性证据。**

## 1. 执行与协议

- 按用户授权保留现有训练／测试划分、目标、容差与不可达案例；实验源码和数据哈希与冒烟版本一致。
- 训练180条，2个epoch，每条两种提示输入；测试每阶段120条。共享15张源图，测试是60个物理任务初值组合各两条指令改写，不是120次独立采集。
- 实测曲线查表／插值；f/16 的T1–T3共18条不可达，主表仍包含这些案例，成功率上限不超过85%。
- 每阶段完整保存原始输出、控制轨迹、策略结果；命中数和调用计量通过逐条复核。
- 完成 9 个模型评测阶段、1080 条阶段记录校验，另有固定中心基线与四任务分项。

基线评分口径审计：原实现仅检查终态真任务亮度／裁剪，不要求控制器自身六帧确认成功；其中 0 条被记为任务达标但控制器未确认。两条件同时成立为 72/120。保留原协议分数，不把它和其他列直接当作等义成功率进行排名。

P1仍获知真任务ROI均值，并使用最近曝光图像；动作预算和信息条件尚未完全对齐。因此本表不能证明任何控制范式的公平优劣。

## 4. 全量LoRA训练

- BF16、r=16，训练样本 180，epochs=2，microsteps=720，optimizer updates=180。
- 训练循环计时 381.35 秒（不含权重加载），adapter保存后已重新加载评测。
- epoch均值loss：1: 0.0288, 2: 0.0001。
- 测试图像与训练重叠，训练后提升不能解释为独立场景泛化；单种子结果没有统计显著性结论。

## 6. 失败模式与未完成项

- 3B零样本＋telemetry：`ValueError: Invalid ROI/grid` × 35；`ValueError: Invalid tolerance_dn` × 75；`ValueError: Invalid target_dn` × 10。
- 7B零样本＋telemetry：`ValueError: Invalid target_dn` × 27；`ValueError: Invalid tolerance_dn` × 17。
- 3B线性图／视觉输入：`ValueError: Invalid ROI/grid` × 120。
- 3B Min-Max／视觉输入：`ValueError: Invalid ROI/grid` × 120。
- 3B双视图网格／视觉输入：`ValueError: Invalid ROI/grid` × 119；`ValueError: Invalid tolerance_dn` × 1。

- 保留18条不可达案例；不能把这些失败归因于模型。机器可读汇总另含可达102条／不可达18条分层统计，但不替换主表分母。
- 缺：独立图像／episode划分；真实SNR／定位／低对比度或OCR验收；真实在线闭环；公平P1信息／动作预算；端到端时延；多种子／置信区间。
- 原方案扩展仍缺：32B／72B、InternVL／LLaVA、1,200独立episodes、三增益轴、T5切换、LoRA r=32/64、3-shot与教师蒸馏。
- generation延迟为CUDA同步后的模型生成时间；总确认时间混合该实测值与240ms/frame、12ms/command假设，不是硬件端到端计时。
